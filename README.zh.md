<h1 align="center">YTDownloader</h1>

<p align="center">
  基于 <a href="https://github.com/yt-dlp/yt-dlp">yt-dlp</a> 构建的 macOS 原生 YouTube 视频下载客户端。<br />
  粘贴 YouTube 链接，选择清晰度即可开始下载，支持暂停/继续与实时进度显示。
</p>

<p align="center">
  <img src="docs/screenshot.png" alt="YTDownloader screenshot" width="800" />
</p>

## 主要特性

- 粘贴 URL 即可自动解析视频标题、封面及可用画质格式
- 支持选择清晰度与音视频格式（MP4、WebM、MP3）
- 实时显示下载进度、下载速度与预估剩余时间
- 支持下载暂停与断点续传

## 安装指南

### Homebrew
```bash
brew tap mrKangHo/tap
brew install youtubedownloader
```
